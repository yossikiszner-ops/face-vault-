# Face Vault

מערכת פרטית לניהול פרופילים, אימון וזיהוי פנים מתמונות או מהמצלמה.

## פריסה ב-Vercel

1. חברו את המאגר ל-Vercel.
2. הוסיפו Upstash Redis דרך Marketplace.
3. הוסיפו משתני סביבה:
   - APP_PASSWORD
   - AUTH_SECRET (מחרוזת אקראית ארוכה)
   - UPSTASH_REDIS_REST_URL
   - UPSTASH_REDIS_REST_TOKEN
4. בצעו Deploy מחדש.

המודל לזיהוי פנים רץ בדפדפן ואינו משתמש ב-API חיצוני של חברת AI. תמונות המקור אינן נשמרות; נשמרת רק חתימת הפנים המספרית. יש להשתמש רק בתמונות שהתקבלה הסכמה מפורשת לעיבודן ולזיהוין.
